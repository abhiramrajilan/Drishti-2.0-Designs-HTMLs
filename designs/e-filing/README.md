# E-Filing

Design flows for the ON Courts e-filing experience, organized by case type.

| Flow | Folder | Status |
|---|---|---|
| Cheque Bounce (S138) | [`cheque-bounce/`](./cheque-bounce/) | ✅ Finished — structured multi-file prototype |

Each finished flow is its own folder with a self-contained structure
(`index.html`, `screens/`, `css/`, `js/`, `assets/`) and its own README
explaining how to run it. See the flow's README for run instructions
(these are **served** projects — they need a local static server, not a
double-click).
