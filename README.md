# Drishti 2.0 — Designs (HTML)

Iterations of the designs being worked on as part of the Drishti 2.0
project.

Contributing? Read [CLAUDE.md](./CLAUDE.md) first — it covers the branch
naming convention, folder structure, and how changes get reviewed and
merged into `main`.

- Team members with write access: branch off `main`, push your work,
  open a PR when it's ready for review.
- Everyone else: fork this repo and open a PR from your fork.

`main` is protected — all changes land through a reviewed, approved PR.
